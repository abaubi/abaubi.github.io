1 Enunciat de l'activitat

L'objectiu d'aquesta Pràctica 4 és analitzar de forma científica i visual el comportament i les limitacions insalvables del control proporcional pur (P pur).

Utilitzant el simulador del forn elèctric, configurarem un regulador continu PID amb acció integral desactivada (T_i = ∞) i acció derivada desactivada (T_d = 0 s). Comprovarem com, per molt que incrementem el guany del regulador (K_p_c), la variable de sortida (y) mai aconsegueix arribar realment al valor de consigna (Setpoint), estabilitzant-se sempre per sota i produint un error permanent en règim permanent o offset.

2 Fonaments Teòrics del Control Proporcional

El control proporcional és la forma de regulació contínua més senzilla. L'actuador no s'encén ni s'apaga bruscament com en el control On-Off, sinó que l'esforç de control és directament proporcional a l'error instantani de mesura:

// Equació bàsica del regulador P pur
u(t) = K_p_c · e(t)
// On:
• e(t) = r(t) - y(t) (Error entre consigna r i sortida y)
• K_p_c : Guany proporcional del controlador
• u(t) : Senyal enviat a l'actuador (limitat físicament entre 0 i U_max)

• Implementació pràctica en JavaScript / Node.js

En un autòmat programable o microcontrolador real que suporti JavaScript (com ara microcontroladors compatibles amb Espruino, o sistemes de telecontrol IoT industrial basats en Node.js), l'algorisme de regulació P pur s'executa de forma cíclica sota un interval de mostreig fix (típicament mitjançant setInterval o interrupcions de temporitzador):

// Paràmetres constants de configuració
const Kp_c = 2.0; // Guany proporcional del controlador (Kp_c)
const Setpoint = 2.0; // Valor de consigna desitjat (r)
const U_max = 5.0; // Voltatge màxim de sortida a l'actuador
// Funció cíclica executada en cada període de mostreig
function calcularAccioProporcional(y_actual) {'{'}
// 1. Càlcul de l'error del sistema
const error = Setpoint - y_actual;
// 2. Càlcul de l'esforç de control ideal
const u_ideal = Kp_c * error;
// 3. Saturació física (l'actuador no pot donar menys de 0V ni més de U_max)
const u_sat = Math.max(0.0, Math.min(U_max, u_ideal));
return u_sat; // Retorna la tensió real a aplicar (en Volts)
{'}'}

Aquest codi mostra la senzillesa i, alhora, el motiu de l'offset: si la variable de procés y_actual arriba al Setpoint, l'error és 0, el que dona una acció de control de 0V que refredarà el sistema immediatament.

• La paradoxa de l'Error Permanent (Offset)

Per què la sortida mai arriba a la consigna? Analitzem-ho físicament en règim permanent (estacionari):

  1. Imagina que la temperatura (y) aconseguís igualar exactament la consigna (r). En aquest instant, l'error seria perfectament zero (e = 0).
  2. Si l'error és zero, el controlador proporcional calcula una sortida nul·la: u = K_p_c · 0 = 0 Volts. L'escalfador s'apaga per complet!
  3. Com que l'escalfador està completament apagat, el forn es refreda immediatament i la temperatura torna a caure per sota de la consigna.
  4. Per tant, per mantener qualsevol temperatura superior a 0 V, l'escalfador necessita rebre una energia contínua (u > 0). I per a que el controlador proportional subministri aquesta tensió, és matemàticament obligatori que existeixi un error permanent diferent de zero (e_offset > 0).

• L'Efecte del Guany K_p_c sobre l'Offset

Mitjançant l'àlgebra de blocs de control, sabem que la sortida final en règim estacionari per a una planta lineal és:

y_permanent = r · ( K_p_c · K_planta ) / ( 1 + K_p_c · K_planta )

On l'error permanent o offset es calcula com:

e_offset = r / ( 1 + K_p_c · K_planta )

S'observa clarament que si augmentem el guany del controlador (K_p_c ↑), el denominador creix i per tant l'error disminueix (e_offset ↓). Tanmateix, mai arribarà a zero per a cap guany finit. A més, un guany massa gran fa augmentar l'oscil·lació o inestabilitat davant de retards de la planta.

3 Guia de Treball Pas a Pas

Pas 1: Control proporcional de guany baix

Configureu la planta de primer ordre pura (K_p = 2.0, τ_1 = 3.0 s, inèrcies secundàries τ_2=τ_3=0, retard θ=0s). Activeu el Bucle Tancat en mode PID, configureu la consigna r = 2.0 V, integral desactivada (T_i = ∞) i derivat desactivat (T_d = 0 s). Ajusteu el guany del regulador a K_p_c = 1.0. Apunteu el valor on s'estabilitza la sortida i verifiqueu que l'error és aproximadament d'uns 0.67 Volts.

Pas 2: Comprovar l'efecte de l'increment de guany

Mantenint la configuració de primer ordre, augmenteu gradualment el guany K_p_c a 2.0, 5.0, i 10.0. Mireu com disminueix la franja d'error (offset) al panell de rendiment. Arribarà mai a 0.000 V? Reflexioneu sobre per què el sistema es manté stable però mai arriba a consigna.

Pas 3: El perill dels guanys elevats amb retard o inèrcies

Introduïu retard o inèrcies a la planta: poseu τ_2 = 1.0 s o retard θ = 1.0 s. Deixeu consigna a r = 2.0 V i activeu un guany alt, per exemple K_p_c = 8.0 o superior. Observeu que en lloc d'apropar-nos més a la consigna, la sortida comença a oscil·lar contínuament o fins i tot es torna completament inestable. Aquest és el límit físic del control P pur en presència de retards.
