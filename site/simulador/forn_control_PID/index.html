Manual MQTT (Pub/Sub)

Llista de tòpics, permisos i rangs de valors del bessó digital

El sistema MQTT usa un tòpic base (ex: iesebre/forn/). Aquest s'afegeix davant de tots els tòpics de la taula. Per exemple, per llegir la temperatura: iesebre/forn/telemetria/temperatura. Pels comandaments s'afegeix /set al final, per exemple: iesebre/forn/setpoint/set. Per cada publicació (excepte per al temps simulat), es publica automàticament un tòpic amb el mateix valor i el sufix -ts sota la subcarpeta ts/ (ex: iesebre/forn/ts/telemetria/resistencia-ts o iesebre/forn/ts/ki-ts) amb el timestamp numèric Unix (en ms) de la darrera publicació.

Tòpic Operador Rang / Valors Descripció
telemetria/temperatura PUB 20.0 – 100.0 (ºC) Temperatura actual del forn
telemetria/energia PUB 0.0+ (kJ) Energia tèrmica acumulada
telemetria/potencia PUB 0.0+ (W) Potència tèrmica subministrada pel calefactor
telemetria/perdues PUB 0.0+ (W) Pèrdues tèrmiques (conductància + de refredament)
telemetria/resistencia PUB 0 – 100 (%) Feedback en temps real de la resistència calefactora (%)
resistencia/set PUB SUB 0 – 100 (%) Consigna d'actuació de resistència en mode manual MQTT. També suporta telemetria/resistencia/set i compatibilitat amb bomba/set.
telemetria/temps PUB 0+ (s) Temps simulat del procés actual
telemetria/alarmaAlta PUB true / false Estat d'alerta per temperatura alta
telemetria/alarmaBaixa PUB true / false Estat d'alerta per temperatura baixa
setpoint PUB SUB 0 – 100 (ºC) Consigna de temperatura desitjada per al forn
ventilador PUB SUB 0 – 100 (%) Velocitat o potència del ventilador de refredament manual. Suporta també comandaments directes a ventilador/set.
mode PUB SUB "PID", "ON_OFF", "HYS", "MQTT" Modalitat de control d'estratègia activa
kp PUB SUB 0 – 500 Constant Proporcional del control PID
ki PUB SUB 0 – 200 Constant Integral del control PID
kd PUB SUB 0 – 500 Constant Derivativa del control PID
pert PUB SUB -150 – +150 Pertorbació o disturbi de potència externa (W)
inercia PUB SUB 1 – 50 Inèrcia o retard tèrmic del calefactor
histeresisp PUB SUB 0.1 – 10.0 (ºC) Banda diferencial d'histèresi pel control ON/OFF
antiwindup PUB "ON", "OFF" Informa si el Clamping d'Anti-Windup està actiu
antiwindup/set PUB SUB "ON", "OFF" Activa o desactiva l'estratègia Anti-Windup
alarmHighsp PUB SUB 20 – 100 (ºC) Llindar superior d'alarma per sobreescalfament
alarmLowsp PUB SUB 0 – 100 (ºC) Llindar inferior d'alarma per refredament excessiu
presetsPID PUB SUB "perfecte", "nomesP", "inestable", "senseSortida" Aplica un preset i activa el mode PID (admet presetsPI per compatibilitat)
ctrl/play PUB SUB "PLAY", "PAUSE" Reprendre o pausar la simulació del forn
ctrl/pas PUB SUB "PAS" Calcula exactament un pas temporal (0.1 segons) en pausa
ctrl/reset PUB SUB "RESET" Reinicia la temperatura del forn a 20.0 ºC i el temps a 0s
tempsFinestra PUB SUB 10 – 600 (s) Rang d'escala temporal visible (eix X)
