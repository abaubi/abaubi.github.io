Regulant sistemes industrials

Un cop entenem la dinàmica de la planta, necessitem un «cervell» que decideixi com actuar. Descobreix com dissenyar i sintonitzar controladors per complir les especificacions més estrictes del món real.

1. Especificacions de disseny temporal

Com avaluem si un controlador fa bé la seva feina? Definim mètriques clares sobre la resposta esglaó del sistema.

tr

Temps de pujada (Rise Time, tr)

Temps necessari perquè la sortida passi del 10% al 90% del seu valor final. Ens indica la rapidesa de reacció del sistema.

Mp

Sobreoscil·lació màxima (Overshoot, Mp)

El valor de pic màxim que assoleix la corba de resposta per sobre del valor de referència final, generalment expressat en percentatge (%). Un excés trenca peces mecàniques.

tp

Temps de pic (Peak Time, tp)

El temps exacte que triga el sistema a arribar al primer pic de màxima sobreoscil·lació.

ts

Temps d'establiment (Settling Time, ts)

Temps que triga la corba a entrar i no sortir mai més d'una banda d'error permesa al voltant del valor final (típicament ±2% o ±5%). Indica quan el sistema ja és "estable".

ess

Error en règim permanent (ess)

Diferència final entre la referència desitjada (consigna) i el valor en què s'estabilitza la màquina quan el temps tendeix a infinit.

Conclusió Crítica

Si el nostre procés és Tipus 0 (com un forn tèrmic) i li demanem una temperatura fixa (Esglaó), la taula indica que hi haurà Error Constant. La solució per anul·lar l'error i convertir la casella en verda és afegir artificialment un integrador mitjançant l'algorisme de control, convertint el conjunt global en Tipus 1 (d'aquí neix la necessitat imperiosa de l'acció Integral Ki als controls PI i PID).

3. Famílies de controladors industrials

Evolució des del control més bàsic fins a l'estàndard d'or industrial.

Tot / Res Control On/Off amb Histèresi

L'actuador només té dos estats: Activat al 100% o Aturat (0%). És barat, robust i comú en termòstats domèstics, o controls de nivell de tancs mitjançant boies.

Per evitar que l'actuador s'encengui i s'apagui contínuament de manera ràpida (provocant el trencament mecànic) s'introdueix una banda d'histèresi (h). El sistema sempre oscil·larà de manera natural entre aquests valors límit.

// S'executa constantment (loop):
let error = consigna - lectura;
let h = 2.0; // Banda de tolerància

if (lectura < consigna - h) {
    actuador = 100; // ENCENDRE TOT
} else if (lectura > consigna + h) {
    actuador = 0;   // APAGAR TOT
}
// Si està al mig, manté l'estat anterior
Comportament On/Off

P Control Proporcional

La resposta de control és un simple multiplicador de l'error instantani: u(t) = Kp · e(t).

  • Molt de guany (Kp alt): Acció ràpida però pot provocar sobreoscil·lacions brusques (perill d'inestabilitat).
  • Poc guany (Kp baix): Sistema mandrós i lent.
El problema endèmic del P: Sempre deixa un error en règim permanent en sistemes de Tipus 0. Si e(t) = 0, llavors u(t) = 0 (el controlador s'atura abans d'arribar). Per mantenir la planta al punt de consigna es requereix energia, per tant l'error mai no pot ser zero si només utilitzem Kp.

PI Control Proporcional Integral

Afegeix l'acumulació matemàtica de l'error en el temps: u(t) = Kp · e(t) + Ki ∫ e(t) dt.

El gran avantatge: L'acció integral **anul·la completament l'error en règim permanent**. Mentre existeixi un error, per petit que sigui, l'integrador seguirà sumant (o restant) i empenyent l'actuador fins a fer diana exactament a la consigna.

Ara bé, l'acció d'acumular retarda el senyal de control i empitjora lleugerament l'estabilitat fent el sistema més prompens a oscil·lar (major Mp).

PID Control PID Complet

La derivació de l'error afegeix un comportament **predictiu**. Analitza a quina velocitat s'acosta el sistema a la consigna. Si va molt ràpid (alta velocitat d'error), l'acció derivativa frena el controlador abans d'arribar, actuant d'amortidor dinàmic per reduir la sobreoscil·lació.

Fórmula completa: u(t) = Kp·e(t) + Ki∫e(t)dt + Kd(de(t)/dt)

Lògica simple en un microcontrolador 
// Bucle d'execució cada (dt) segons
error = consigna - lecturaReal;

// 1. Proporcional
P = Kp * error;

// 2. Integral (Suma acumulada)
integral = integral + (error * dt);
I = Ki * integral;

// 3. Derivatiu (Variació respecte el passat)
D = Kd * (error - errorAnterior) / dt;

// Acció total de control
sortida = P + I + D;

// === PROTECCIÓ ANTI-WINDUP ===
// Evitar acumular I en va si la planta no pot donar més
if (sortida > MAXIM_PERMES) {
    sortida = MAXIM_PERMES;
    integral = integral - (error * dt); // Desfer
} else if (sortida < MINIM_PERMES) {
    sortida = MINIM_PERMES;
    integral = integral - (error * dt); // Desfer
}

// Guardar estat pel següent cicle
errorAnterior = error;
Per què millora el "Anti-Windup"?

Imagina que demanes a un vehicle anar a 200 km/h però el motor físicament només pot donar 120 km/h. L'actuador estarà saturat (límit = 100%). Mentre no assoleixis els 200, l'error és positiu i la component Integral (I) continuarà sumant matemàticament fins a l'infinit inútilment ("Windup").

Si després redueixes la consigna a 50 km/h, l'integrador triga moltíssim temps en desfer la memòria acumulada. El sistema no frenarà immediatament. L'Anti-Windup talla aquesta acumulació falsa quan s'arriba al límit mecànic.

4. Mètodes de sintonització empírica

Trobar els valors òptims de Kp, Ki i Kd quan no tenim les equacions del model matemàtic físic exacte.

Pas 1 Sintonització Manual (Prova i error guiat)

Si l'operari pot veure com reacciona el sistema a temps real sense perill de trencar res, l'ajust manual és molt comú. Cal seguir un ordre molt estricte per no descontrolar la màquina:

1. Ajustar Kp (Amb Ki=0, Kd=0)

Augmenta el guany proporcional a poc a poc fins que la resposta arribi ràpid, però comenci a oscil·lar contínuament lleugerament al voltant de la consigna. Llavors abaixa'l a la meitat.

2. Ajustar Ki

Al pas 1 segurament ens haurà quedat un error constant. Incrementa progressivament el terme integral fins que l'error s'elimini en un temps acceptable per al procés.

3. Ajustar Kd (Opcional)

Si el sistema fa masses "botets" (oscil·la molt) abans d'estabilitzar-se pel pes del component integral, puja la component derivativa per actuar de fre i suavitzar la corba d'arribada.

2. Assaig de Relé (Mètode del Guany Últim / Autotuning)

Llaç tancat

Se substitueix momentàniament el PID per un relé On/Off per forçar que el sistema oscil·li contínuament de manera segura. Si coneixem l'amplitud que injecta el relé (d) i observem què respon el sistema llegit pel sensor, trobarem el límit d'inestabilitat matemàtic. Aquest és el mètode usat a l'Autotune de PLCs (Siemens, Arduino, etc.).

De l'oscil·lació resultant prenem mesures:
  • Període crític (Tu): El temps d'un cicle complet d'oscil·lació.
  • Amplitud d'oscil·lació llegida (a).
  • Calculem el Guany Últim (Ku) amb la fórmula: Ku = 4·d / (π·a)
