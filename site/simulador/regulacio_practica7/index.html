Pràctica 7: El fenomen del "Wind-up" i la solució Anti-windup

Saturació de l'acció integral — Analitzar la saturació de l'acció integral i com evitar-la amb Clamping (Anti-windup)

1 Enunciat de l'activitat (Pràctica 7)

L'objectiu de la Pràctica 7 és analitzar el perillós fenomen del "Wind-up" o saturació de l'acció integral i avaluar la seva solució mitjançant l'algorisme de Clamping (Anti-windup).

L'acció integral elimina l'error de posició o offset sumant els petits errors de forma acumulativa en el temps. Malauradament, tots els actuadors físics reals tenen límits físics de funcionament (ex. saturació de 0V a 5V o de potència de 0% a 100%).

Si el sistema es troba sotmès a un error constant que no pot corregir-se immediatament (ex. demanar temperatura superior a la potència màxima del calefactor), el controlador treballarà saturat al 100%. Com que l'error continua sent positiu, l'acció integral continuarà calculant i sumant errors indefinidament ("wind-up" o enrotllament de la integral). En arribar finalment a la consigna, la integral té un valor gegantí que triga molts segons a descarregar-se, provocant sobrepicos descontrolats i inestabilitat severa.

2 Fonaments Teòrics de la Saturació Integral i Anti-windup

Quan un regulador PID ideal funciona en un sistema real, el senyal calculat u_ideal(t) es topa amb el limitador de saturació física de l'actuador:

// Model de saturació de l'actuador físic
u(t) =
• uMax si u_ideal(t) > uMax
• u_ideal(t) si 0 ≤ u_ideal(t) ≤ uMax
• 0V si u_ideal(t) < 0V

• Què passa exactament durant el "Integral Wind-up"?

Mentre l'actuador està saturat al seu valor màxim, el sistema es troba en bucle obert efectiu. Això significa que per molt que la integral continuï acumulant valor, la planta no rebrà més energia de la que el seu limitador físic (uMax) pot donar.

  • L'error acumulat a l'acumulador integral creix linealment sense cap utilitat física.
  • Quan el setpoint torna a un nivell accessible o hi ha un canvi de consigna descendent, el controlador no respon immediatament. Primer necessita que l'error passi a ser negatiu durant molt de temps per poder "desenrotllar" o rebaixar tota la integral acumulada inserviblement (fase de "wind-down").
  • Aquest retard de descàrrega condueix a un sobrepic gegantí i pot destruir l'estabilitat del sistema.

• Procés de càlcul de l'Anti-windup (Clamping)

A continuació es detalla el pseudocodi del càlcul del regulador i el mètode de Clamping o integració condicional per evitar la saturació desmesurada:

// Executat a cada període de mostreig dt
const error = setpoint - mesura;
const pTerm = Kp_c * error;
const dTerm = Kp_c * Td * ((error - errorAnterior) / dt);
const iTermPrev = (Ti !== Infinity) ? (Kp_c / Ti) * integralAcumulada : 0;
// Senyal ideal de control i aplicació de límits
const u_ideal = pTerm + iTermPrev + dTerm;
const u_saturada = Math.max(0.0, Math.min(uMax, u_ideal));
// Lògica Clamping: Atura la integració si l'actuador està saturat
// i l'error actual té el mateix signe que el senyal ideal calculated
const estaSaturat = (u_ideal !== u_saturada);
const mateixSigne = Math.sign(error) === Math.sign(u_ideal);
const congelarIntegrador = estaSaturat && mateixSigne;
// Integració condicional
if (!congelarIntegrador && Ti !== Infinity) {
integralAcumulada += error * dt;
}
