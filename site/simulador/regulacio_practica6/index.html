Pràctica 6: Regulació Proporcional-Integral-Derivativa (PID) completa

Controlador PID continu — Analitzar l'efecte esmorteïdor de l'acció derivativa (Td) sobre el transitori

1 Enunciat de l'activitat

L'objectiu d'aquesta Pràctica 6 és analitzar de forma pràctica l'efecte esmorteïdor de l'acció derivativa (T_d) en un sistema de control de temperatura o posició en llaç tancat (PID).

En les pràctiques anteriors, vam comprovar que l'acció Proporcional combinada amb l'acció Integral (regulador PI) és molt útil per aconseguir error permanent nul. No obstant això, quan la planta té fortes inèrcies (múltiples constants de temps com τ_2 i τ_3) o retard temporal significatiu (θ), el control PI esdevé altament oscil·latori o inestable, requerint molt de temps per estabilitzar-se.

Introduint la constant de temps derivada (T_d) aconseguirem un efecte "anticipador" o "fre predictiu". L'acció derivativa mesura la velocitat a la qual varia l'error i actua en contra d'aquest canvi, esmorteïnt radicalment les oscil·lacions i disminuint notablement el sobrepic (overshoot) de la planta.

2 Fonaments Teòrics de la Regulació PID Completa

Un regulador PID calcula de manera simultània tres accions diferents basades en el senyal d'error e(t), sumant els seus efectes per calcular el senyal de control final u(t):

// Equació paral·lela ideal del regulador PID
u(t) = K_p_c · e(t) + (K_p_c / T_i) · ∫ e(τ) dτ + K_p_c · T_d · [ de(t) / dt ]
// On:
• K_p_c : Guany proporcional del controlador (força bruta de reacció)
• T_i : Constant de temps integral (elimina l'offset acumulant errors)
• T_d : Constant de temps derivada (anticipa i frena mesurant la tendència)
• de(t)/dt : Velocitat instantània de canvi de l'error

• L'Acció Derivativa com a "Fre Predictor"

Mentre que l'acció Proporcional mira el present i la Integral mira el passat, la Derivativa mira cap al futur (fa una predicció lineal basada en el pendent actual de l'error):

  • Quan la temperatura o posició del procés comença a pujar ràpidament cap a la consigna, l'error disminueix ràpidament. Això vol dir que la derivada de l'error és negativa (de/dt < 0).
  • L'acció derivativa, en multiplicar-se per aquest pendent negatiu, resta de l'esforç de control (u(t)), actuant com un fre aerodinàmic o amortidor actiu.
  • Aquest efecte evita que la planta es passi de llarg de la consigna (redueix l'overshoot) i suprimeix les oscil·lacions transitories ràpidament.

• Algorisme PID Complet en JavaScript (Euler discretitzat)

A continuació es detalla la implementació exacta de l'algorisme de regulació PID en sistemes encastats reals, com PLCs, microcontroladors o el nostre propi simulador en temps real:

let integralError = 0.0; // Acumulador de l'acció integral
let lastError = 0.0; // Error del cicle anterior per calcular la derivada
// Funció de control executada periòdicament cada 'dt' segons
function calcularControlPID(consigna, mesura, Kpc, Ti, Td, dt, uMax) {"{"}
const error = consigna - mesura;
// 1. Acció Proporcional (P)
const pTerm = Kpc * error;
// 2. Acció Integral (I)
if (Ti > 0 && Ti !== Infinity) {"{"}
integralError += error * dt;
{"}"} else {"{"}
integralError = 0.0;
{"}"}
const iTerm = (Ti > 0 && Ti !== Infinity) ? (Kpc / Ti) * integralError : 0.0;
// 3. Acció Derivativa (D) - Velocitat instantània del canvi d'error
const dTerm = (Td > 0) ? Kpc * Td * ((error - lastError) / dt) : 0.0;
// 4. Esforç Ideal Combinat
const uIdeal = pTerm + iTerm + dTerm;
// 5. Saturació física de l'actuador (Límit de maquinari)
const uSaturada = Math.max(0.0, Math.min(uMax, uIdeal));
// 6. Anti-windup condicional per evitar la saturació integral
if (uIdeal !== uSaturada && Ti > 0 && Ti !== Infinity) {"{"}
if (Math.sign(error) === Math.sign(uIdeal)) {"{"}
integralError -= error * dt; // Desfà la integració inútil
{"}"}
{"}"}
lastError = error; // Desar l'error actual per al proper cicle
return uSaturada;
{"}"}

• El Perill dels Sorolls i el "Derivative Kick" en T_d alta

Tot i que l'acció de derivar aporta una enorme estabilitat, presenta dos greus problemes físics en aplicacions reals:

  • Amplificació del soroll d'alta freqüència: Qualsevol sensor físic (per exemple una sonda de temperatura PT100) té petites fluctuacions de soroll d'alta freqüència. Com que la derivada mesura velocitat de canvi, la derivada de fluctuacions molt ràpides (pendent molt vertical) genera un senyal enorme, provocant que l'actuador commuti bruscament, fent vibrar elements mecànics i danyant les vàlvules.
  • Filtre de derivació: Per aquest motiu, en la pràctica industrial s'afegeix un filtre pas-baix d'alta freqüència en sèrie amb el derivador, d'aquesta manera es processa només la tendència macro de la temperatura i es descarta el soroll micro del sensor.

3 Guia de Treball Pas a Pas

Pas 1: Resposta d'un sistema molt oscil·latori amb regulació PI (Td = 0 s)

Configureu el simulador extern amb retard i inèrcies reals: τ_1 = 3.0 s, τ_2 = 1.5 s, τ_3 = 0.5 s, retard θ = 0.8 s. Activeu el PID Continu, amb consigna r = 2.0 V, guany K_p_c = 2.5 i constant integral T_i = 4.0 s. Inicialment, configureu la constant derivada a T_d = 0.0 s.
Observeu com les inèrcies acumulades i el temps mort fan que el sistema lliuri fortes oscil·lacions transitories amb un sobrepic molt elevat. Anoteu el sobrepic (%) i el temps d'estabilització.

Pas 2: Introducció de l'acció derivada (Td) com a fre predictiu

Amb els mateixos paràmetres físics de la planta, aneu introduint gradualment acció derivada. Proveu a pujar el valor a T_d = 0.5 s, després 1.0 s, i finalment 1.5 s. Observeu com a mesura que puja T_d, les ones es redueixen notablement en amplitud, el sobrepic baixa radicalment i el temps d'estabilització és molt menor. Fixeu-vos com la corba de control blava s'anticipa fent una davallada ràpida del voltatge per frenar la sortida abans d'arribar a la consigna.

Pas 3: L'inconvenient d'un excés d'acció derivada (Td massa gran)

Pugeu la constant derivada T_d per sobre dels límits de seguretat escolar (proveu T_d = 3.5 s o 4.5 s). Mireu el senyal blau de control: veureu l'aparició de ràpides oscil·lacions brusques (micro-commutacions). Argumenteu per què aquests impulsos danyarien els actuadors en entorns de fàbrica.
