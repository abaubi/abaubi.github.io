Fonaments del control manual

La sintonització manual per "prova i error" és el mètode més immediat quan no disposem d'un model matemàtic del procés. Consisteix a ajustar els tres paràmetres actuant directament sobre els components físics:

  • Kp (Proporcional): Multiplica l'error actual. Puja el Kp per accelerar la planta i respondre amb força, però vés amb compte: un Kp massa alt provoca oscil·lacions inestables (sobrepic exagerat).
  • Ki (Integral): Acumula l'error en el temps. S'encarrega d'esborrar l'error residual permanent o "offset" (el buit que queda entre la mesura real i la consigna). Si el puges massa, el sistema oscil·larà de manera molt lenta i pesant.
  • Kd (Derivatiu): Mesura la velocitat de variació de l'error ("frena" el canvi). Actua com un amortidor anticipant-se a les desviacions abruptes, permetent reduir els sobrepics inicials.

Procediment pas a pas recomanat

  1. Posa Ki i Kd a zero.
  2. Puja Kp progressivament fins que el sistema faci en règim transitori un sobrepic just per baix del màxim que vulguis suportar. Deixa el Kp a aquest valor.
  3. Puja Ki a poc a poc per eliminar l'error estacionari (la diferència permanent amb la consigna).
  4. Augmenta lleugerament Kd per esmorteir el sobrepic mantenint la resposta estable en règim permanent.

En aquest gràfic unificat s'observa el comportament característic de cada acció:
• Només Kp (taronja): Presenta oscil·lacions esmorteïdes (el primer pic és clarament el més alt) que s'estabilitzen amb un error permanent (offset) per sota del Setpoint.
• Kp + Ki (blau): L'acció integral elimina l'error permanent i assoleix exactament el Setpoint, però a canvi d'introduir una resposta oscil·latòria més acusada, on el primer sobrepic és el més alt i va decreixent en cicles successius.
• PID Complet (verd): L'acció derivativa (Kd) afegeix amortiment, reduint dràsticament el primer sobrepic i aconseguint una resposta excel·lentment estabilitzada en un temps rècord.

Sintonia per Llaç Obert (Ziegler-Nichols)

Es basa a aplicar un "assaig de resposta temporal" de la planta en bucle obert (sense PID actiu). S'aplica un salt de potència (graó) al PWM de l'actuador (representat com Δu) i es registra la gràfica de la il·luminació del sensor des de l'inici del salt.

Variables Calculades i Explicació Física

Guany del Procés (K)

Indica quant varia la sortida per unitat d'actuació física:

K =
Δy Δu
=
ΔLux ΔPWM
Retard Temporal (L)

El temps mort inicial (en s) que transcorre abans de detectar canvis en el sensor. Representa inèrcies pures de transport de llum i electricitat.

Const. de Temps (τ)

El temps extra necessari per a que el sensor assoleixi el 63.2% de la seva diferència de valor total, un cop vençut el retard.

Exemple Pràctic Numèric
Identificació de les variables de la corba

Prenent com a referència un assaig real dut a terme a la planta d'aquest simulador, es defineixen els següents valors numèrics de les variables del gràfic:

Increment Llum (Δy) 600 Lux De 150 a 750 Lux
Graó Actuació (Δu) 1000 u. Salt de PWM (0 a 1000)
Guany Planta (K) 0.60 K = 600 / 1000
Retard Mort (L) 0.40 s Temps de resposta
Const. Temps (τ) 2.20 s Fins al 63.2%
Càlcul dels paràmetres PID per Ziegler-Nichols (Llaç Obert):
• Kp = 1.2 · (τ / (K · L)) = 1.2 · (2.20 / (0.60 · 0.40)) = 1.2 · (2.20 / 0.24) = 11.00
• Ti = 2 · L = 2 · 0.40 s = 0.80 s ⟶ Ki = Kp / Ti = 11.00 / 0.80 = 13.75 s⁻¹
• Td = 0.5 · L = 0.5 · 0.40 s = 0.20 s ⟶ Kd = Kp · Td = 11.00 · 0.20 = 2.20 s

Com ho programes tu? (Microcontrolador propi, p. ex. Arduino)

1. Desactiva el control automàtic i posa la sortida manual a 0 (p. ex. analogWrite(pin, 0)). Espera que el sensor s'estabilitzi en repòs.
2. Comença a enviar dades de temps (en mil·lisegons) i de la lectura del sensor LDR a través del port sèrie.
3. Genera un graó brusc de sortida manual al 100% de potència (p. ex. analogWrite(pin, 255)) i enregistra les dades fins a la saturació completa.
4. Mitjançant les dades capturades, s'analitza el gràfic per a obtenir els valors de L i τ per sintonitzar la taula anterior.

Codi Arduino: Assaig de Resposta (Llaç Obert) C++ / Arduino IDE 
// ====================================================================
// PROGRAMA DE CAPTURA D'ASSAIG DE RESPOSTA EN GRAÓ (LLAÇ OBERT)
// ====================================================================
const int PIN_LED = 9;       // Actuador: Sortida PWM que controla la il·luminació (LED)
const int PIN_LDR = A0;      // Sensor: Entrada analògica de llum (LDR)

unsigned long tempsInici = 0;
bool graoAplicat = false;

void setup() {
  Serial.begin(115200);      // Inicialitza la comunicació Sèrie a alta velocitat
  pinMode(PIN_LED, OUTPUT);
  analogWrite(PIN_LED, 0);   // Inicialment en repòs absolut (sortida u = 0)
  
  // Capçalera per importar en full de càlcul (Excel/CSV) o obrir amb Serial Plotter
  Serial.println("Temps_ms,Lectura_Sensor_LDR");
  delay(3000);               // Espera de 3 segons per assegurar l'estabilització del repòs
}

void loop() {
  unsigned long ara = millis();
  int lectura = analogRead(PIN_LDR); // Llegim el sensor (valor de 0 a 1023)
  
  // Envia les dades de manera contínua
  Serial.print(ara);
  Serial.print(",");
  Serial.println(lectura);
  
  // Al cap de 5 segons, apliquem un graó complet d'actuació (PWM de 0 a 255, és a dir Δu = 255)
  if (ara > 5000 && !graoAplicat) {
    analogWrite(PIN_LED, 255); // Forcem l'encesa total immediata del LED
    graoAplicat = true;
    Serial.println("# GRAÓ APLICAT ARA!");
  }
  
  delay(50);                 // Període de mostreig fix de 50 mil·lisegons
}
Gràfic de la corba de reacció en S
El retard (L) és l'eix mort de temps des del graó d'entrada fins on comença a aixecar-se la línia tangent vermella. La constant de temps (τ) és la projecció de la tangent sobre els nivells de repòs i de saturació màxima de llum.

Assaig de Relé d'Åström-Hägglund (Llaç Tancat)

Aquest és un dels mètodes industrials més potents, segurs i fàcils de programar de forma nativa. En lloc de fer un assaig en llaç obert que podria fer col·lapsar el procés o cremar resistències, l'assaig d'Åström manté el sistema controlat mitjançant un commutador ON-OFF (relé) amb histèresi per forçar una oscil·lació controlada al voltant del setpoint de consigna.

Conceptes Matemàtics Clau

  • Amplitud d'Actuació (d): És l'amplitud elèctrica o física del pols d'actuació que genera el relé (en aquest simulador, conmuta de 0 a 1000, per tant d = 1000).
  • Amplitud detectada (A): La meitat de la variació d'oscil·lació aconseguida en el sensor de Lux un cop estabilitzada la seqüència:
    A =
    Luxmax - Luxmin 2
  • Període Crític (Pu): És el període temporal de l'oscil·lació sostinguda (mesurat com el temps entre dos pics consecutius).
  • Guany Crític (Ku): S'obté mitjançant la fórmula d'anàlisi del primer harmònic del relé:
    Ku =
    4 · d π · A

Càlculs de Sintonització Finals (Llaç Tancat)

Tipus Kp Ti (Integral) Td (Derivatiu) Equació en Ki / Kd
P 0.5 · Ku — — Ki = 0 / Kd = 0
PI 0.45 · Ku 0.83 · Pu — Ki = Kp / (0.83 · Pu)
PID 0.6 · Ku 0.5 · Pu 0.125 · Pu

Com ho programes tu? (Arduino o PLC real)

1. Dins del bucle d'execució d'alta velocitat, escriu un algorisme ON/OFF que commuta la sortida manual PWM entre SORTIDA_MAX i SORTIDA_MIN quan la lectura del sensor creua la consigna amb histèresi h: if (lecturaLux < Setpoint - h) SortidaPWM = SORTIDA_MAX;
else if (lecturaLux > Setpoint + h) SortidaPWM = SORTIDA_MIN; 2. Guarda en variables temporals els mil·lisegons en què la lectura creua exactament el Setpoint en la mateixa direcció per calcular el període crític Pu (el temps transcorregut entre creuaments consecutius en el mateix sentit).
3. Registra el màxim i mínim valor que assoleix el sensor de Lux dins de cada cicle per obtenir l'amplitud d'oscil·lació: A = Luxmax - Luxmin 2 .
4. Un cop obtingudes unes 3 o 4 oscil·lacions estables, calcula el guany crític Ku i aplica les constants finals de sintonització PID d'acord amb la taula superior.

Codi Arduino: Autotuner d'Åström (Relé amb Histèresi) C++ / Arduino IDE 
// ====================================================================
// ALGORISME D'AUTOTUNING PER ASSAIG DE RELÉ (LLAÇ TANCAT)
// ====================================================================
const int PIN_LED = 9;         // Pin del LED d'actuació (Sortida PWM)
const int PIN_LDR = A0;        // Pin del sensor LDR (Lectura analògica)

// Paràmetres de l'assaig d'Åström
const float SETPOINT = 500.0;  // Consigna desitjada de Lux
const float HYSTERESIS = 15.0; // Amplitud de la histèresi h
const float PWM_MAX = 255.0;   // Actuació alta (SORTIDA_MAX)
const float PWM_MIN = 0.0;     // Actuació baixa (SORTIDA_MIN)
const float AMP_D = (PWM_MAX - PWM_MIN) / 2.0; // Amplitud d'oscil·lació del relé (d = 127.5)

// Variables d'estat de l'autotuner
unsigned long darrerCreuament = 0; // Enregistra el temps de l'últim creuament pel SP
float maxValorCicle = -9999.0;     // Màxim assolit dins d'un cicle
float minValorCicle = 9999.0;      // Mínim assolit dins d'un cicle
int ciclesComplets = 0;            // Comptador de cicles completats d'oscil·lació
bool sobreSetpointAnterior = false;

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED, OUTPUT);
  Serial.println("Iniciant assaig de sintonització automàtica per Relé d'Åström...");
}

void loop() {
  float y = analogRead(PIN_LDR);   // Llegir valor actual del sensor
  unsigned long ara = millis();
  
  // 1. Control per relé ON/OFF amb histèresi h
  float u = 0;
  if (y < (SETPOINT - HYSTERESIS)) {
    u = PWM_MAX;                   // Massa fosc: encesa al màxim
  } else if (y > (SETPOINT + HYSTERESIS)) {
    u = PWM_MIN;                   // Massa clar: apagada total
  } else {
    // Ens trobem dins la banda d'histèresi: mantenim l'estat anterior
  }
  analogWrite(PIN_LED, u);

  // 2. Guardar els pics màxims i mínims de l'oscil·lació
  if (y > maxValorCicle) maxValorCicle = y;
  if (y < minValorCicle) minValorCicle = y;

  // 3. Detecció del creuament del Setpoint per analitzar període
  bool sobreSetpointAra = (y > SETPOINT);
  if (sobreSetpointAra && !sobreSetpointAnterior) {
    // S'ha produït un creuament de pujada pel setpoint
    if (darrerCreuament > 0) {
      unsigned long tempsCicle = ara - darrerCreuament; // Temps d'un cicle complet
      float Pu = tempsCicle / 1000.0;                   // Converteix a segons (Pu)
      float A = (maxValorCicle - minValorCicle) / 2.0;  // Amplitud d'oscil·lació (A)
      
      ciclesComplets++;
      Serial.print("Cicle "); Serial.print(ciclesComplets);
      Serial.print(" completat: Pu = "); Serial.print(Pu); Serial.print("s");
      Serial.print(", Amplitud A = "); Serial.println(A);

      // Després d'assegurar 3 cicles estables, calculem els paràmetres del PID
      if (ciclesComplets >= 4) {
        float Ku = (4.0 * AMP_D) / (3.14159 * A);      // Guany Crític Ku
        
        // Fórmules Ziegler-Nichols (Llaç Tancat)
        float Kp = 0.60 * Ku;
        float Ki = Kp / (0.50 * Pu);
        float Kd = Kp * (0.125 * Pu);
        
        Serial.println("\n--- SINTONITZACIÓ DE CONSTANTS FINALS ---");
        Serial.print("Guany Crític (Ku): "); Serial.println(Ku);
        Serial.print("Període Crític (Pu): "); Serial.print(Pu); Serial.println(" segons");
        Serial.print(">> Proporcional (Kp): "); Serial.println(Kp);
        Serial.print(">> Integral (Ki): ");     Serial.println(Ki);
        Serial.print(">> Derivatiu (Kd): ");     Serial.println(Kd);
        Serial.println("-----------------------------------------\n");
      }
    }
    
    // Reiniciem els valors extrems per al següent cicle d'oscil·lació
    darrerCreuament = ara;
    maxValorCicle = -9999.0;
    minValorCicle = 9999.0;
  }
  sobreSetpointAnterior = sobreSetpointAra;
  
  delay(10); // Execució periòdica del llaç tancat de relé
}
Gràfica de l'assaig d'Åström (Relé) u (Període Crític) t (Temps) y, u
L'assaig de relé converteix el sistema en un oscil·lador controlat de cicle límit. D'aquí s'extreu el període de l'oscil·lació Pu i l'amplitud d'ona resultant A per calcular un guany crític proporcional segur.

Manual MQTT (Pub/Sub)

Llista de tòpics, permisos i rangs de valors del bessó digital

El sistema MQTT usa un tòpic base (ex: iesebre/llum/). Aquest s'afegeix davant de tots els tòpics de la taula. Per exemple, per llegir la lluminositat: iesebre/llum/telemetria/lux. Pels comandaments s'afegeix /set al final, per exemple: iesebre/llum/setpoint/set. Per cada publicació (excepte per al temps simulat), es publica automàticament un tòpic amb el mateix valor i el sufix -ts sota la subcarpeta ts/ (ex: iesebre/llum/ts/telemetria/resistencia-ts o iesebre/llum/ts/ki-ts) amb el timestamp numèric Unix (en ms) de la darrera publicació.
