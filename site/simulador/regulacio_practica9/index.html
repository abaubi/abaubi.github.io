Pràctica 9: Sintonització de controladors (Ziegler-Nichols en Llaç Obert)

Determinació de constants (K, L, τ) mitjançant la corba de reacció en S i configuració del bucle tancat PI / PID per homologar els KPIs.

1 Enunciat i Objectiu de la Pràctica 9 (Ziegler-Nichols en Llaç Obert)

L'objectiu de la Pràctica 9 és aplicar el mètode de Sintonia de Llaç Obert (Ziegler-Nichols), que es basa en l'anàlisi de la resposta temporal d'una planta de segon ordre en bucle obert (sense el regulador actiu) quan és sotmesa a una excitació de tipus graó.

En l'àmbit industrial, aquest assaig permet extreure els paràmetres dinàmics essencials de la planta de manera ràpida i senzilla: el guany (K), el retard mort (L) i la constant de temps (τ). A partir d'aquestes tres variables, s'apliquen un conjunt de relacions matemàtiques fixes per calcular de forma directe els paràmetres del controlador P, PI o PID.

Activitat principal: Realitzareu un assaig en llaç obert aplicant un escaló de potència al PWM de l'actuador (Δu = 1000). A partir de la corba de reacció obtinguda, calculareu la configuració òptima dels reguladors PI i PID complets i en comprovareu l'eficàcia en llaç tancat davant dels estrictes indicadors clau de rendiment (KPIs de disseny).

2 Fonaments de la Sintonia per Llaç Obert (Ziegler-Nichols)

L'assaig s'inicia estabilitzant la planta en repòs absolut (u = 0). Seguidament, s'aplica un escaló brusc de sortida manual (Δu, per exemple, de 0 a 1000 u. PWM) i s'enregistra la corba de reacció en S.

Guany del Procés (K) K = Δy / Δu = ΔLux / ΔPWM Mesura la sensibilitat física de la planta: la variació del sensor de lluminositat respecte a la potència aplicada.
Retard Temporal (L) Temps mort inicial (s) El període des que s'aplica l'escaló fins que el sensor comença a detectar un canvi (inèrcies de transport).
Const. de Temps (τ) Temps al 63.2% de Δy El temps necessari perquè la lluminositat assoleixi el 63.2% del salt total una vegada superat el retard.
Tipus Controlador Guany Proporcional (Kp) Temps Integral (Ti) Temps Derivatiu (Td) Equació Equivalent Ki / Kd
Proporcional (P) τ / (K · L) — — Ki = 0 / Kd = 0
Proporcional-Integral (PI) 0.9 · τ / (K · L) 3 · L — Ki = Kp / (3 · L)
Complet (PID) 1.2 · τ / (K · L) 2 · L 0.5 · L Ki = Kp / (2 · L)
Kd = Kp · 0.5 · L

El retard (L) és l'eix mort de temps des del graó d'entrada fins on comença a aixecar-se la línia tangent vermella. La constant de temps (τ) és la projecció de la tangent sobre els nivells de repòs i de saturació màxima de llum.

3 Especificacions de Disseny del Client (KPIs d'Homologació)

Per homologar el nostre controlador PID sota la sintonia de Ziegler-Nichols per Llaç Obert, el bucle tancat ha de satisfer els següents indicadors de qualitat enfront d'un escaló a t = 1.0 s amb consigna r = 500 lx (o 3.0 V equivalents):

1. Error permanent (Offset) Offset ≤ 2.0 lx La resposta s'ha de clavar de forma extremadament precisa al voltant de la consigna.
2. Temps de Pujada (Rise Time) t_r ≤ 3.5 s El temps transcorregut fins que la il·luminació assoleix per primera vegada el 90% de la consigna.
3. Sobrepic Màxim (Overshoot) Mp ≤ 15.0 % L'oscil·lació inicial de seguretat no ha de depassar els 575 lx davant la consigna de 500 lx.
4. Temps d'Estabilització (Settling Time) t_s ≤ 8.0 s El temps en que la mesura del sensor entra i es manté de forma permanent dins de la banda del ±2% de la consigna.

⚠️ Atenció: El mètode clàssic de Ziegler-Nichols sol introduir respostes una mica agressives amb sobrepics propers al 20-30%. L'addició precisa de l'acció derivada és crucial per esmorteir el control i homologar amb èxit els KPIs!

4 Exemple de Càlcul de Paràmetres i Constants PID

Imaginem que realitzem l'assaig en manual aplicant un graó d'actuació de Δu = 1000 u. PWM (passem la potència de 0 a 1000). A partir del registre de la corba en S del sensor, s'obtenen les següents lectures físiques:

• Lluminositat inicial (Repòs): y_inicial = 150 lx
• Lluminositat final (Estabilitzada): y_final = 750 lx
• Increment de llum (Δy): 750 lx - 150 lx = 600 lx
• Temps d'inici de l'escaló: t_escalo = 1.00 s
• Temps on la corba comença a pujar (creuament de la tangent): t_tangent = 1.40 s
• Temps on s'assoleix el 63.2% del canvi total (~529 lx): t_63.2 = 3.60 s

1. Càlcul dels 3 paràmetres de la planta

Guany de la planta (K) K = Δy / Δu = 600 / 1000 = 0.60
Retard mort (L) L = t_tangent - t_escalo = 0.40 s
Constant de temps (τ) τ = t_63.2 - t_tangent = 2.20 s

2. Aplicació de les equacions de Ziegler-Nichols

A) Sintonització del Controlador PI
• Kp = 0.9 · τ / (K · L) = 0.9 · 2.20 / (0.60 · 0.40) = 1.98 / 0.24 = 8.25
• Ti = 3 · L = 3 · 0.40 s = 1.20 s
• Ki = Kp / Ti = 8.25 / 1.20 = 6.875 s⁻¹
B) Sintonització del Controlador PID Complet
• Kp = 1.2 · τ / (K · L) = 1.2 · 2.20 / (0.60 · 0.40) = 2.64 / 0.24 = 11.00
• Ti = 2 · L = 2 · 0.40 s = 0.80 s ⇒ Ki = Kp / Ti = 11.00 / 0.80 = 13.75 s⁻¹
• Td = 0.5 · L = 0.5 · 0.40 s = 0.20 s ⇒ Kd = Kp · Td = 11.00 · 0.20 = 2.20 s

5 Algorisme en JavaScript per a la Programació d'Autotuning

Per implementar un autotuning automàtic en un ordinador industrial, un autòmat programable (PLC) o un microcontrolador (com un microprocessador que monitoritzi la il·luminació), podem programar un algorisme de detecció en JavaScript. Aquest mètode utilitza el mètode pràctic de dos punts característics (28.3% i 63.2%) per identificar L i tau de manera immuna al soroll del sensor de luxs, evitant els errors de calcular la tangent de manera numèrica directe:

algorisme_autotuning.js Vanilla JS / TS 
/**
 * Algorisme d'identificació i autotuning de Ziegler-Nichols (Llaç Obert)
 * @param {Array<{t: number, y: number, u: number}>} samples Historial de mostres d'assaig
 * @returns {Object} Joc final de paràmetres Kp, Ki, Kd i model de planta
 */
function calcularAutotuningZN(samples) {
  if (samples.length < 10) return null;

  // 1. Cercar estat inicial (u_repòs i y_inicial d'estabilització)
  const initialSamples = samples.slice(0, 5);
  const y_inicial = initialSamples.reduce((acc, s) => acc + s.y, 0) / 5;
  const u_inicial = initialSamples.reduce((acc, s) => acc + s.u, 0) / 5;

  // 2. Detectar l'escaló (graó d'entrada Δu) i el seu instant inicial t0
  let t_escalo = 0;
  let u_final = u_inicial;
  for (let i = 1; i < samples.length; i++) {
    if (samples[i].u > samples[i-1].u + 100) { // Salt significatiu de PWM
      t_escalo = samples[i].t;
      u_final = samples[samples.length - 1].u;
      break;
    }
  }
  const delta_u = u_final - u_inicial;
  if (delta_u <= 0) return null;

  // 3. Cercar el valor d'estabilització final y_final (mitjana del final)
  const finalSamples = samples.slice(-10);
  const y_final = finalSamples.reduce((acc, s) => acc + s.y, 0) / 10;
  const delta_y = y_final - y_inicial;
  if (delta_y <= 10) return null; // Resposta inaudible o nul·la

  // Calcular guany del procés K
  const K = delta_y / delta_u;

  // 4. Mètode dels 2 punts (immunitat al soroll):
  // Determinarem el temps quan s'assoleix el 28.3% i el 63.2% de l'increment total de y
  const y_target28 = y_inicial + 0.283 * delta_y;
  const y_target63 = y_inicial + 0.632 * delta_y;

  let t_28 = -1;
  let t_63 = -1;

  for (let i = 0; i < samples.length; i++) {
    if (samples[i].t >= t_escalo) {
      if (t_28 === -1 && samples[i].y >= y_target28) {
        t_28 = samples[i].t;
      }
      if (t_63 === -1 && samples[i].y >= y_target63) {
        t_63 = samples[i].t;
      }
    }
  }

  if (t_28 === -1 || t_63 === -1) return null;

  // Càlcul dels temps transcorreguts des de l'escaló
  const t28_elapsed = t_28 - t_escalo;
  const t63_elapsed = t_63 - t_escalo;

  // Fórmules del model de segon ordre aproximat:
  const tau = 1.5 * (t63_elapsed - t28_elapsed);
  const L = t63_elapsed - tau;

  // Evitar valors negatius o zero per inestabilitats
  const L_ajustat = Math.max(0.1, L);
  const tau_ajustada = Math.max(0.1, tau);

  // 5. Càlcul dels reguladors de Ziegler-Nichols (Llaç Obert)
  // Regulador PI
  const Kp_pi = (0.9 * tau_ajustada) / (K * L_ajustat);
  const Ti_pi = 3 * L_ajustat;
  const Ki_pi = Kp_pi / Ti_pi;

  // Regulador PID complet
  const Kp_pid = (1.2 * tau_ajustada) / (K * L_ajustat);
  const Ti_pid = 2 * L_ajustat;
  const Td_pid = 0.5 * L_ajustat;
  const Ki_pid = Kp_pid / Ti_pid;
  const Kd_pid = Kp_pid * Td_pid;

  return {
    planta: { K, L: L_ajustat, tau: tau_ajustada, delta_y, delta_u },
    PI: { Kp: Kp_pi, Ki: Ki_pi, Kd: 0 },
    PID: { Kp: Kp_pid, Ki: Ki_pid, Kd: Kd_pid }
  };
}

*Nota: L'ús de mètodes basats en punts característics és la pràctica estàndard en autotunings d'equips industrials per evitar de fer derivades directes de senyals sorollosos, fet que faria fallar el mètode de la tangent geomètrica directa de la Figura 1.
