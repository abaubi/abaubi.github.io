MONITOR SÈRIE SCADA

Guia de l'Usuari - Sala de Pintura Multivariable

1. Descripció del Sistema

El simulador representa el control ambiental d'una sala de pintura industrial. Per obtenir un acabat de pintura professional, cal mantenir constants i acoblades la Temperatura (T) i la Humitat Relativa (H) dins de la cabina.

2. Símbols i Equivalències Elèctriques

  • Temperatura (T): Rang de 0ºC a 100ºC. S'obté mitjançant una sonda de temperatura industrial que dóna un senyal de 0-10 V (on 10V = 100ºC).
  • Humitat (H): Rang de 0% a 100% HR. S'obté d'una sonda que dóna un senyal de 0-10 V (on 10V = 100% HR).
  • Actuadors (u_T, u_H): Corresponen a la potència del calefactor (u_T) i obertura de la vàlvula de vapor (u_H) regulats de 0 a 100%.

3. El Problema de l'Acoblament Multivariable

Aquest sistema és altament acoblat (MIMO), el que significa que l'acció d'un actuador afecta la variable de l'altre:

  • El Calefactor (u_T) escalfa la sala, de manera natural, però alhora asseca l'aire (fa baixar la humitat, H).
  • El Sistema d'Humitat (u_H) augmenta la humitat, però a causa de l'evaporació o efecte adiabàtic, fa baixar la temperatura (T).
  • Podeu ajustar aquests efectes amb els guanys creuats de la planta: K_TH (Calefactor asseca la Humitat) i K_HT (Humitat refreda la Temperatura).

4. Mètodes de Desacoblament

Per solucionar l'acoblament, l'SCADA permet triar tres modes de funcionament:

  • Sense desacoblament: Els PIDs actuen de forma independent directe sobre els actuadors. S'observaran fortes oscil·lacions en creuar consignes.
  • Opció A (Matriu Completa): Aplica una matriu de desacoblament creuat que calcula les senyals reals corregides per neutralitzar els efectes encreuats.
  • Opció B (Compensació Simplificada): Aplica una correcció simplificada compensant directament l'efecte proporcional d'un llaç sobre l'altre.

5. Modes de Control de cadascun dels Reguladors

  • PID: Algorisme proporcional-integral-derivatiu amb l'opció d'Anti-Windup (AW) per evitar la saturació de la part integral.
  • On-Off: Control de tot o res bàsic.
  • Histeresi: Control tot o res millorat amb un marge simètric ajustat pel slider de Histeresi.
  • Manual/MQTT: Permet fixar directament el percentatge de sortida de l'actuador amb el slider de Control Manual.

6. Integració MQTT (SCADA Bi-direccional)

El simulador es pot connectar a qualsevol Broker MQTT (p. ex. HiveMQ o broker local) utilitzant protocols WebSockets (wss://). Els tòpics suportats són:

  • iesebre/salapintura/telemetria : Envia un JSON complet amb l'estat en temps real.
  • iesebre/salapintura/telemetria/temperatura : Temperatura de la sala.
  • iesebre/salapintura/telemetria/humitat : Humitat de la sala.
  • iesebre/salapintura/cmd : Rebre ordres JSON per controlar el simulador remotament. Exemples d'accions disponibles:
    • {"action": "start"}: Inicia el cicle de simulació.
    • {"action": "stop"}: Atura la simulació.
    • {"action": "reset"}: Reinicia la simulació als valors inicials.
    • {"config": {"tempSetpoint": 30, "humSetpoint": 50}}: Modifica les consignes de temperatura i humitat.
    • {"config": {"tempControlMode": "PID", "humControlMode": "ON_OFF"}}: Modifica el mode de control (opcions: 'PID', 'ON_OFF', 'HYSTERESIS', 'MANUAL').
    • {"config": {"decouplingMode": "MATRIX"}}: Modifica el mode de desacoblament (opcions: 'NONE', 'MATRIX', 'SIMPLIFIED').
  • iesebre/salapintura/telemetria/control_temp/set : Rebi un valor de potència de calefactor directa en mode Manual.
  • iesebre/salapintura/telemetria/control_hum/set : Rebi un valor d'obertura de vàlvula directa en mode Manual.
