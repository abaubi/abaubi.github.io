Com configurar Firebase?

  1. Crea un projecte a Firebase Console.
  2. Afegeix una aplicació Web i copia les claus d'aquí al costat.
  3. Ves a Authentication, clica "Get Started" i activa Email/Password i Google.
  4. Important per Google Login: A Authentication > Settings > Authorized domains, afegeix el domini d'aquesta aplicació:
  5. Ves a Firestore Database i clica "Create database" (en mode producció).
  6. A la pestanya Rules de Firestore, esborra-ho tot i enganxa això:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null && request.auth.uid == request.resource.data.userId;
    }
  }
}
